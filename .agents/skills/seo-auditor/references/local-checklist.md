# Lokalne SEO Checklist (Polska)

Używaj gdy strona ma charakter lokalny (usługi, gabinety, sklepy stacjonarne, restauracje, firmy regionalne).

## NAP Consistency (Name, Address, Phone)
- [ ] Nazwa firmy, adres i telefon są identyczne na stronie, w stopce, w schemacie i w Google Business Profile
- [ ] Brak wariantów nazwy (np. „Firma X” vs „Firma X Sp. z o.o.”)
- [ ] Numer telefonu w formacie polskim (+48 lub 0XX)
- [ ] Adres zawiera kod pocztowy i miasto

## Google Business Profile (GBP)
- [ ] Profil istnieje i jest zweryfikowany (sprawdź publicznie)
- [ ] Kategorie główne i dodatkowe są trafne
- [ ] Godziny otwarcia aktualne
- [ ] Zdjęcia (w tym własne, nie stock)
- [ ] Posty / aktualności (jeśli aktywne)
- [ ] Recenzje — liczba, średnia, odpowiedzi właściciela

## Schema & Structured Data
- [ ] LocalBusiness lub bardziej precyzyjny typ (Dentist, LegalService, Restaurant itd.)
- [ ] Poprawne pola: name, address, telephone, openingHours, geo, url, image
- [ ] AggregateRating jeśli są recenzje

## Treść lokalna
- [ ] Strona główna i podstrony usług zawierają lokalne frazy (miasto + usługa)
- [ ] Podstrony lokalizacji (jeśli wiele miast) — unikalna treść, nie thin
- [ ] Mapa Google osadzona (z poprawnym adresem)
- [ ] Sekcja „O nas” / zespół z lokalnym kontekstem

## Cytowania i zaufanie (polskie realia)
- [ ] Spójne dane w popularnych źródłach (jeśli publicznie widoczne)
- [ ] NIP / KRS / REGON widoczne (sygnał zaufania)
- [ ] Polityka prywatności i regulamin obecne
- [ ] Dane kontaktowe łatwo dostępne (nie tylko formularz)

## Ryzyka lokalne
- [ ] Brak lub bardzo słaby GBP
- [ ] Niespójny NAP
- [ ] Thin landing pages pod miasta
- [ ] Brak recenzji lub tylko negatywne bez odpowiedzi
