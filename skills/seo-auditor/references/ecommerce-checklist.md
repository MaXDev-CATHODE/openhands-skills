# E-commerce SEO Checklist

Używaj dla sklepów (WooCommerce, Shoper, PrestaShop, Shopify, IdoSell, custom).

## Product Pages
- [ ] Unikalne title i meta description (nie tylko „Produkt | Sklep”)
- [ ] H1 = nazwa produktu
- [ ] Unikalny opis produktu (min. 150–300 słów własnej treści, nie kopia producenta)
- [ ] Product schema (name, image, description, sku, offers, aggregateRating, brand)
- [ ] Cena, dostępność, waluta poprawnie oznaczone w schema
- [ ] Zdjęcia zoptymalizowane + alt z nazwą produktu
- [ ] Internal linking do kategorii i powiązanych produktów
- [ ] Recenzje / opinie klientów (jeśli są)

## Category & Collection Pages
- [ ] Unikalna treść wprowadzająca (nie tylko lista produktów)
- [ ] Title i meta zoptymalizowane pod kategorię
- [ ] H1 jasny
- [ ] Breadcrumbs z schema
- [ ] Paginacja SEO-friendly (lub load more z poprawnym fallbackiem)
- [ ] Filtry / facety — canonical lub noindex na wariantach parametrów (unikanie duplicate)

## Technical e-com
- [ ] Out-of-stock pages — co się dzieje? (redirect, noindex, czy zostają z informacją)
- [ ] Parametry URL (sortowanie, filtry) nie generują masowego indeksowania
- [ ] Sitemap zawiera produkty i kategorie (aktualna)
- [ ] Szybkość — szczególnie LCP na stronach produktowych (duże zdjęcia)
- [ ] Mobile — przyciski, warianty, koszyk używalne

## Content & Thin pages
- [ ] Brak thin product pages (krótki opis producenta + nic więcej)
- [ ] Kategorie nie są puste lub prawie puste
- [ ] Blog / poradniki wspierają topical authority (jeśli istnieją)

## Polskie e-commerce realia
- [ ] Popularne platformy: sprawdź typowe błędy WooCommerce (Yoast/RankMath konflikty), Shoper, PrestaShop
- [ ] Ceny i dostępność aktualne
- [ ] Trust signals: opinie, zwroty, dane firmy (NIP), metody płatności
- [ ] Lokalne dostawy / odbiór osobisty jako sygnał

## Ryzyka
- [ ] Masowe thin product pages
- [ ] Duplicate content z opisów producentów
- [ ] Faceted navigation bez kontroli indeksacji
- [ ] Słabe internal linking między produktami a kategoriami
