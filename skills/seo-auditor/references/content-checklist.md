# Content & E-E-A-T Checklist

## Intencja i pokrycie
- [ ] Treść precyzyjnie odpowiada głównej intencji wyszukiwania (informacyjna / transakcyjna / nawigacyjna / lokalna)
- [ ] Odpowiedź na pytanie użytkownika pojawia się w pierwszych 100–150 słowach
- [ ] Pokrycie tematu jest głębsze lub co najmniej równe top 3–5 konkurentom
- [ ] Brak oczywistych luk tematycznych (ludzie też pytają / related searches)

## E-E-A-T (szczególnie ważne w polskim Google)
- [ ] Doświadczenie (Experience) — widoczne realne przykłady, case studies, zdjęcia własne, dane własne
- [ ] Ekspertyza (Expertise) — autor/zy z kwalifikacjami, bio, linki do profili
- [ ] Autorytet (Authoritativeness) — cytowania, wzmianki, linki z wiarygodnych źródeł
- [ ] Zaufanie (Trustworthiness) — polityka prywatności, kontakt, dane firmy, aktualne informacje, brak clickbait
- [ ] Dla YMYL (zdrowie, finanse, prawo) — znacznie wyższe wymagania

## Jakość i unikalność
- [ ] Brak thin content (< 300–400 słów bez wartości dodanej na stronach docelowych)
- [ ] Brak duplicate / near-duplicate między podstronami
- [ ] Treść nie jest oczywistym AI-generowanym bełkotem (powtarzalne frazy, brak głębi, generyczne przykłady)
- [ ] Fakty, ceny, daty, oferty są aktualne
- [ ] Unikalna wartość (dane własne, oryginalne wnioski, lokalny kontekst polski)

## On-page content signals
- [ ] Title i H1 spójne z intencją i treścią
- [ ] Naturalne użycie głównego słowa kluczowego + wariantów + LSI
- [ ] Dobre nagłówki H2/H3 tworzące logiczną strukturę
- [ ] Listy, tabele, akapity — scannability
- [ ] Internal links do powiązanych treści (kontekstowe, nie tylko footer)
- [ ] CTA jasne i zgodne z intencją

## Readability & UX treści
- [ ] Język dopasowany do odbiorcy (nie zbyt akademicki, nie zbyt potoczny)
- [ ] Krótkie akapity, white space
- [ ] Media wspierające (obrazy, video, infografiki) z alt i opisem
- [ ] Brak ściany tekstu

## Specjalne sygnały AI Overviews / SGE
- [ ] Jasna, cytowalna definicja / odpowiedź na górze
- [ ] Struktura ułatwiająca ekstrakcję (listy, tabele, FAQ)
- [ ] Silne E-E-A-T i autorstwo
- [ ] Aktualność i oryginalność
